# 词义三选一

一个给 iPad 用的中文词义练习器。单文件网页，离线可用。

## 内容

题库 5489 道：

- 词语 4327
- 成语 1088
- 短语 74

每题给一个词，三个选项里只有一个是最准确的意思；选完会列出三个选项的释义。
分类只有：全部 / 词语 / 成语 / 短语。

题库不收网络流行语、生造词和人名。

## 在 iPad 上用

1. 电脑和 iPad 连同一个 Wi-Fi。
2. 双击 `启动服务.bat`，窗口里会显示 `iPad 打开：http://...`。
3. 在 iPad 的 Safari 里打开这个地址。
4. 点 Safari 的分享按钮，选“添加到主屏幕”。

电脑要开着，黑窗口不能关。第一次启动如果 Windows 问是否允许访问网络，选“允许”。

也可以直接把 `index.html` 放到任意静态网页空间。

## 文件

- `index.html`：完整应用（单文件，含题库和样式）
- `serve.js`：局域网静态服务器
- `启动服务.bat`：一键启动
- `使用说明.txt`：给使用者看的说明
- `_开发/app.part.html`：源文件
- `_开发/build.js`：构建脚本，运行 `node _开发/build.js` 生成 `index.html`

## 数据

成绩和错题存在浏览器的 localStorage 里，只在本机，不上传。
